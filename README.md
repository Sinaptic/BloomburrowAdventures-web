# Bloomburrow Adventures (web build)

Play: https://sinaptic.github.io/BloomburrowAdventures-web/

This repo only hosts the exported web build of Bloomburrow Adventures, a hex-crawl adventure mode for Magic: The Gathering set in Bloomburrow, made with Godot 4.6. The files are generated and published automatically; don't edit them here.

Card images are loaded at runtime from Scryfall. Magic: The Gathering and Bloomburrow are trademarks of Wizards of the Coast. This is an unofficial fan project.
